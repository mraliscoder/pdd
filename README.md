# ПДД · Практика

Локальное веб-приложение для чтения ПДД России и подготовки по билетам AB и CD. Готовый сайт находится в `dist/`; сервер и сборка интерфейса не требуются при размещении на статическом хостинге. Все данные и изображения загружены локально, внешние API при чтении и тренировке не используются.

## Запуск

Нужен Node.js 22 или новее. В PowerShell:

```powershell
cd E:\Projects\pdd\pdd-study
npm.cmd start
```

Открыть http://localhost:4173. Зависимости нужны только для повторного импорта текста, для запуска готового сайта установка пакетов не требуется. Открытие `index.html` через `file://` не поддерживается: JSON загружается по HTTP.

## Публикация на GitHub Pages

Workflow: `.github/workflows/deploy-pages.yml`. Он запускается при push в `main` и вручную через **Actions → Deploy to GitHub Pages → Run workflow**. Публикация разрешена только из `main`.

1. Загрузите содержимое папки `pdd-study` в корень GitHub-репозитория: рядом должны лежать `.github/`, `dist/`, `tests/` и `package.json`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions** ([инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)).
3. Отправьте изменения в `main` или запустите workflow вручную для этой ветки. Адрес сайта появится в результате задания **Publish** и в **Settings → Pages**.

Перед публикацией выполняются проверка синтаксиса JavaScript и все тесты логики и данных. При ошибке сайт не публикуется. Workflow передаёт только `dist/`; скачивание исходных материалов и установка зависимостей для этого не нужны. Для авторизации используется встроенный `GITHUB_TOKEN`, отдельный PAT или секрет не требуется.

Относительные пути к ресурсам и маршруты через `#` поддерживают адреса вида `https://OWNER.github.io/REPOSITORY/` без изменения кода. На GitHub Pages приложение работает как обычный статический сайт, без входа через ChatGPT. Прогресс остаётся в браузере и не переносится автоматически с адреса Sites.

## Возможности

- 26 разделов ПДД; приложения о знаках и разметке, допуск транспорта и перечень неисправностей — всего 48 разделов.
- Поиск по всему тексту, размер шрифта, отметки прочитанных разделов, скачивание ПДД в TXT.
- Изображения знаков и горизонтальной/вертикальной разметки возле их номеров в тексте; по нажатию — увеличенная карточка с нормативным описанием. Номера пунктов правил не заменяются иллюстрациями.
- Иллюстрированный каталог: 298 знаков, а также дорожная разметка.
- По 40 билетов / 800 вопросов для каждой группы AB и CD. Всего 1600 вопросов.
- Обучение с немедленным объяснением и тест с разбором в конце.
- Тренировки по темам, случайные тесты на 10/20/40/100 вопросов, марафон по всей выбранной подборке (до 800 вопросов).
- Экзамен: четыре целых случайных тематических блока по пять вопросов, 20 минут; дополнительные 5 или 10 вопросов за ошибки в разных блоках; провал при третьей ошибке, двух в одном блоке или ошибке в дополнительных вопросах.
- Сохранение незавершённого занятия, таймера, избранного, ошибок и истории в localStorage. Прогресс AB/CD разделён по идентификаторам вопросов.
- Повторение ошибок, экспорт прогресса в JSON, адаптивный интерфейс и управление ответами клавишами 1–5.

## Источники и ограничения

Текст: постановление Правительства РФ от 23.10.1993 № 1090, редакция от **28.08.2026**, загружено 23.10.2026 из [КонсультантПлюс](https://www.consultant.ru/document/cons_doc_LAW_2709/). Нормативные формулировки сохранены, служебные справки об истории правок удалены. Исходные HTML-снимки находятся в `sources/law/`, удобный текст — `dist/data/pdd.txt`.

Вопросы и пояснения: [etspring/pdd_russia](https://github.com/etspring/pdd_russia), коммит `fa37933b2ea686db47c64401773e53f6775b8df0` от 02.09.2026. Это учебная копия открытого репозитория: идентичность текущему официальному банку МВД не подтверждена. Не выдавайте приложение за официальный сервис Госавтоинспекции.

Изображения знаков: полный снимок этого репозитория `721d017cb9553820f9cd2bf268cc135cb8501adb` от 29.01.2025. Более новая версия содержит 22 отсутствующих файла и изменения, не совпадающие с приложением ПДД. Каталог служит иллюстрированным справочником; нормативные описания и условия применения берутся из актуального текста ПДД. Указание источника не заменяет проверку условий использования сторонних материалов перед самостоятельным распространением.

Механика экзамена: [регламент МВД, пункты 130–139](https://www.consultant.ru/document/cons_doc_LAW_380236/f8d7876883620f8f1511a9ca70054b464f2f2619/). Тренировки без таймера и марафон не имитируют экзамен, это отдельные учебные режимы.

Данные не обновляются автоматически. Прогресс хранится только в браузере на конкретном адресе; локальная и опубликованная версии имеют раздельное хранилище. Экспорт JSON сохраняет резервную копию, импорт прогресса пока не реализован. Для работы без интернета запустите локальную копию; кэширование всего сайта сервис-воркером не используется.

## Проверка

```powershell
npm.cmd test
```

16 тестов: комплектность билетов, валидность ответов, наличие всех изображений, полнота разделов и ссылок на знаки/разметку, различение одинаковых номеров пунктов и иллюстраций, формирование блоков, все варианты результата основного этапа, дополнительные вопросы без повторов, сохранение полного состава марафона.

## Повторный импорт

```powershell
npm.cmd ci --ignore-scripts
git clone --depth 1 https://github.com/etspring/pdd_russia.git sources/pdd_russia
npm.cmd run import
npm.cmd test
```

Если репозиторий уже есть, сначала обновите его явно до нужной версии. `node scripts/import-data.mjs --cached` повторно разбирает сохранённые HTML-снимки. Скрипт проверяет число разделов и полноту билетов; перед выпуском новой версии нужно проверить дату редакции, изменения экзаменационных вопросов и иллюстрации.

`node scripts/enrich-rule-references.mjs` обновляет только привязки иллюстраций в существующем `rules.json` из локальных снимков `sources/law/`. Перед записью он проверяет полное совпадение текста и числа абзацев; редакция правил и дата загрузки сохраняются.

## Структура

- `dist/` — автономный статический сайт и данные.
- `dist/engine.js` — чистые функции экзамена и выборки вопросов.
- `dist/app.js`, `dist/style.css` — интерфейс и локальный прогресс.
- `scripts/import-data.mjs` — воспроизводимая загрузка и нормализация.
- `scripts/serve.mjs` — локальный HTTP-сервер.
- `tests/engine.test.mjs` — проверки логики и данных.
- `.openai/hosting.json` — конфигурация размещения Sites.

`sources/` и `node_modules/` не входят в публикуемые файлы.
